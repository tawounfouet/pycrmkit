## 5. Safe post-merge evidence workflow prepared

\`.github/workflows/campaign-rc1-exact-main-evidence.yml\` is **workflow_dispatch only**, has **read-only GitHub permissions**, requires the **actual 40-hex main SHA**, refuses an existing rc1 tag, checks completed exact-main push workflows, builds wheel/sdist, checks version/resources and smokes a clean core-only wheel.

\`scripts/rc1_release_bundle.py\` produces **four bytes-verified, source-SHA-bound evidence files**:

1. \`pycrmkit-1.2.0rc1-py3-none-any.whl\`
2. \`pycrmkit-1.2.0rc1.tar.gz\`
3. \`SHA256SUMS-v1.2.0rc1.txt\`
4. \`release-manifest-v1.2.0rc1.json\`

The manifest always records \`publication_authorized=false\` and \`publication_state=EVIDENCE_ONLY_NOT_RELEASED\`. The workflow does **not** merge, tag, upload GitHub Release assets or publish to PyPI. These steps remain subject to release approval.
