# ContactRepository Contract

`ContactRepository` is a domain-oriented protocol. It never exposes ORM sessions, SQLAlchemy expressions, Django QuerySets, tables, or model names.

```python
class ContactRepository(Protocol):
    def get(self, contact_id: ContactId) -> Contact: ...
    def find(self, contact_id: ContactId) -> Contact | None: ...
    def save(self, contact: Contact) -> None: ...
    def archive(self, contact_id: ContactId, archived_at: datetime) -> Contact: ...
    def search(self, query: ContactQuery, page: OffsetPageRequest) -> Page[Contact]: ...
```

`get()` raises `NotFoundError`; `find()` is the explicit nullable lookup. Search uses exact counts, deterministic `created_at ASC, id ASC` ordering, and excludes archived contacts unless `include_archived=True`.
