# PyCRMKit 1.1.0a1 — Query Expressions & Segment Foundations

This release implements **PV1-LOT-001**, the first engineering increment after PyCRMKit 1.0.0 Production Stable.

## Delivered

~~~text
QueryExpression AST
    ↓
QuerySchema
    ↓
Segment
├── STATIC
└── DYNAMIC
    ↓
Memory evaluator
    ↓
crm.segments
~~~

### Domain

- `SegmentId`
- `Segment`
- `SegmentMember`
- `SegmentMode.STATIC`
- `SegmentMode.DYNAMIC`
- `SegmentStatus`

### Query model

- `Predicate`
- `And`
- `Or`
- `Not`
- typed `QueryField`
- `QuerySchema`
- expression schema version 1

### Memory adapter

- Segment repository
- stored membership repository
- Dynamic query evaluator
- deterministic pagination

### Facade

~~~python
crm.segments.create_static(...)
crm.segments.create_dynamic(...)
crm.segments.preview(...)
crm.segments.evaluate(...)
crm.segments.add_member(...)
crm.segments.remove_member(...)
~~~

## Compatibility

PyCRMKit 1.0 remains the frozen compatibility baseline. 1.1.0a1 is additive.

SQLAlchemy/PostgreSQL and Django Segmentation persistence are intentionally deferred to the beta milestones.
