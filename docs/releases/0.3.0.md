# PyCRMKit 0.3.0 — Sales Foundation Stable

`0.3.0` promotes the qualified `0.3.0rc1` Sales Foundation to stable without
adding a new business domain or changing the release-candidate facade surface.

## Stable scope

- Decimal-safe Money;
- Lead capture, qualification, disqualification and conversion;
- Opportunity domain;
- configurable Pipelines and ordered Stages;
- explicit transition policies;
- default Stage probabilities and Stage entry timestamps;
- won/lost terminal outcomes;
- atomic and idempotent Lead-to-Opportunity conversion;
- normalized Sales Events and transactional Audit;
- stable `0.3.x` public API contract.

## Stable guarantees

The final qualification preserves the release-candidate guarantees:

1. a Lead must be qualified before public conversion;
2. conversion creates exactly one Opportunity at the domain workflow level;
3. Contact and optional Organization links are preserved during conversion;
4. a supplied Pipeline places the Opportunity in its initial Stage;
5. equivalent retries with the same idempotency key return the same Opportunity;
6. conflicting idempotency-key reuse is rejected;
7. undeclared Pipeline transitions are rejected;
8. terminal Stages close Opportunities as won/lost/cancelled with terminal probabilities;
9. Sales Events preserve actor/correlation context;
10. Audit commits transactionally with domain state;
11. stable `0.1` and `0.2` facade contracts remain compatible.

## Stable facade surface

```text
crm.leads.create/qualify/disqualify/convert
crm.opportunities.create/move
crm.pipelines.define/get/list
```

The complete contract is documented in `docs/api/0.3-public-api.md`.

## Compatibility

The documented Sales surface is compatibility-governed for the `0.3.x`
release line. Patch releases may fix defects, improve documentation and harden
validation without intentionally breaking this public surface.

## Deferred scope

This release does not introduce Communication/email, durable event delivery,
webhooks, SQLAlchemy/PostgreSQL, FastAPI, Django, Sales Timeline projection,
import/export/deduplication, analytics or AI.

The next implementation milestone is **`0.4.0a1 — Communication Domain`**.
