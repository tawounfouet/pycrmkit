# PyCRMKit 0.5.0b1 — Webhook Registrations

This beta introduces the persistent subscription model that the later webhook
delivery engine will consume.

## Added

- typed `WebhookSubscriptionId` and `WebhookSubscription`;
- validated HTTP(S) endpoint registration;
- exact registered-event filtering;
- active/disabled subscription lifecycle;
- backend-neutral repository contract;
- official Memory repository and Unit-of-Work participation;
- `WebhookSubscriptionService`;
- `crm.webhooks.register(...)`;
- `crm.webhooks.disable(...)`;
- `crm.webhooks.list(...)`;
- custom `EventRegistry` injection for custom public event contracts;
- privacy-conscious registration/disable audit records.

## Filtering contract

A subscription is eligible only when:

```text
subscription.enabled is True
AND
event.type is in subscription.event_types
```

The service also validates the concrete `DomainEvent` against the configured
registry before returning delivery matches.

## Security boundary

This release validates registration syntax but performs no outbound request.
It therefore does not claim transport-level SSRF protection, TLS enforcement,
signature security or response handling.

Those controls belong to the delivery layer.

## Deferred

`0.5.0b2` adds transport, HMAC signing, retry/backoff, delivery logging,
idempotency and dead-letter behavior.
