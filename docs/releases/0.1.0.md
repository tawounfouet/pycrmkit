# PyCRMKit 0.1.0 — CRM Core Stable

`0.1.0` is the first stable PyCRMKit CRM Core milestone. It promotes the functionality qualified through `0.1.0rc1` without introducing a new domain area.

## Included capabilities

```text
Core Primitives
Contacts
Organizations
Relationships
Tags
Custom Fields
Memory Adapter
Unit of Work
Domain Events
Audit
CRM Facade
```

The recommended entry point is:

```python
from pycrmkit import CRM

crm = CRM.memory()
contact = crm.contacts.create(first_name="Ada", last_name="Lovelace")
```

## Stable release gate

The release gate requires:

```text
unit tests
repository contract suites
Memory adapter tests
Unit of Work transaction tests
Events/Audit transaction tests
CRM facade tests
full CRM Core E2E
public API smoke tests
Ruff lint + format check
mypy strict
MkDocs strict build
wheel + sdist build
twine artifact validation
clean-wheel installation
installed CRM.memory() functional smoke
Python 3.11 / 3.12 / 3.13 CI qualification
```

## Compatibility freeze

The supported `0.1` public surface is documented in [PyCRMKit 0.1 Public API](../api/0.1-public-api.md). Internal adapter/runtime modules are intentionally excluded from that promise.

## Deferred to later milestones

Activities/Timeline begin in `0.2.0a1`. SQLAlchemy/PostgreSQL, FastAPI, Django, import/export/deduplication, and durable webhook/event delivery remain later roadmap items.
