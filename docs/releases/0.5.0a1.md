# PyCRMKit 0.5.0a1 — Event Registry & Serialization

This alpha starts the Eventing & Webhooks roadmap by governing the public
event contracts already emitted by stable PyCRMKit domains.

## Added

- `EventDefinition` for one event type/schema contract;
- `EventRegistry` with exact resolution, latest-version lookup, deterministic
  listing, duplicate rejection and unknown-contract errors;
- `default_event_registry()` containing 41 stable v1 event contracts;
- `EventSerializer` for registry-validated dictionary and deterministic JSON
  round trips;
- canonical `contact.created` v1 serialization fixture.

## Compatibility

Stable root and facade APIs from 0.1–0.4 remain unchanged. Existing
`DomainEvent.to_dict/from_dict` behavior is preserved.

Registry validation is scoped to the public serialization boundary in this
alpha. Internal/custom event creation remains possible.

## Deferred

`0.5.0a2` continues with correlation/causation integration. Webhook
subscriptions and the delivery engine remain scheduled for `0.5.0b1/b2`.
