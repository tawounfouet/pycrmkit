# PyCRMKit 0.2.0 — Activity & Timeline Stable

`0.2.0` promotes the qualified `0.2.0rc1` Activity, Task and Timeline surface to stable without adding a new business domain.

## Stable scope

- first-class Activities with explicit historical business occurrence time;
- first-class Tasks with protected lifecycle transitions;
- immutable Timeline read model projected from meaningful Activity and Task events;
- Contact/Organization relationship-history queries;
- Memory repository adapters and shared Unit of Work transaction semantics;
- event/audit context propagation inherited from the CRM facade;
- stable public API contract for the `0.2.x` line.

## Stable guarantees

The final qualification preserves the release-candidate guarantees:

1. imported historical Activity timestamps are ordered by business occurrence time rather than ingestion time;
2. Contact and Organization Timeline views stay consistent for shared Activity/Task references;
3. Task lifecycle transitions remain explicit: `created → started → completed → reopened → cancelled`;
4. Timeline projection commits or rolls back atomically with the source mutation;
5. replay of an identical source event is idempotent and conflicting replay is rejected;
6. Timeline ordering and exact offset pagination are deterministic;
7. temporal filters use half-open windows `[occurred_from, occurred_until)`;
8. `crm.timeline` remains read-only at the facade boundary;
9. the `0.1` root imports and CRM Core namespaces remain compatible.

## Runtime qualification

The stable release is qualified on Python 3.11, 3.12 and 3.13 through GitHub Actions, plus an installed-wheel smoke of the public `CRM.memory()` path.

## Compatibility

The documented Activity, Task and Timeline surface in `docs/api/0.2-public-api.md` is compatibility-governed for `0.2.x`. Patch releases may fix defects and harden validation without intentionally breaking that documented surface.

## Deferred scope

This release does not introduce Sales/Pipeline, SQLAlchemy/PostgreSQL, Django/FastAPI, webhooks, durable event delivery, transactional outbox, asynchronous projections or cursor-based search pagination.
