# PyCRMKit 1.2.0a3 — Attribution & Communication Linkage

This release implements **PV1-LOT-010**.

## Delivered

~~~text
Campaign
├── attribution references
│   ├── CRM target
│   ├── normalized source
│   ├── optional external reference
│   └── provenance metadata
│
└── communication links
    └── existing CommunicationRecord
~~~

## Attribution references

`CampaignAttributionReference` is intentionally lightweight.

It records:

- the Campaign;
- one existing CRM entity reference;
- a normalized source label;
- an optional external reference;
- the recorded timestamp;
- actor/provenance metadata.

Supported targets remain the CRM entity kinds already accepted by Segmentation:

~~~text
contact
organization
lead
opportunity
~~~

There is deliberately no weighting, scoring, multi-touch model, first-touch
model or last-touch calculation in this alpha.

~~~python
crm.campaigns.add_attribution(
    campaign.id,
    EntityReference("opportunity", opportunity.id),
    source="linkedin organic",
    external_ref="utm-2026-q4",
)
~~~

## Communication linkage

Campaigns may link to existing CRM `CommunicationRecord` objects:

~~~python
crm.campaigns.link_communication(
    campaign.id,
    communication.id,
    role="follow-up",
)
~~~

The link does not:

~~~text
send a message
queue delivery
select recipients
render a template
retry a provider
modify delivery history
~~~

It only records CRM-level provenance.

Read APIs:

~~~python
crm.campaigns.communication_links(campaign.id)
crm.campaigns.communications(campaign.id)
~~~

## Public events

~~~text
campaign.attribution_added
campaign.attribution_removed
campaign.communication_linked
campaign.communication_unlinked
~~~

## Persistence boundary

Memory is the reference implementation for LOT-010.

SQLAlchemy/PostgreSQL and Django persistence for Campaign metadata, audience,
attribution and communication linkage remain grouped in the beta milestones.

## Compatibility

The `1.2.0a1` metadata and `1.2.0a2` audience contracts remain available
unchanged. PyCRMKit 1.1 remains the stable compatibility baseline.
