# PyCRMKit 1.1.0a2 — Saved Queries & Advanced Segment Semantics

This release implements **PV1-LOT-002**.

## Delivered

~~~text
SavedQuery
    ↓
revisioned reusable selection semantics
    ↓
QueryExpression schema v2
    ├── RelativeTimeValue
    ├── Custom Fields
    ├── Tags
    └── deterministic ordering
    ↓
Memory evaluator
    ↓
crm.saved_queries
~~~

### SavedQuery

- typed stable identity and key;
- private/shared visibility;
- revision history;
- optimistic update preconditions;
- archive lifecycle;
- deterministic ordering;
- execution and preview APIs.

### Query enhancements

- relative time anchored to the injected Clock;
- minutes / hours / days / weeks;
- scalar Custom Field predicates through `custom.<key>`;
- Tag predicates through `tag`;
- explicit ASC/DESC ordering and null placement;
- expression serialization schema **v2**, retaining v1 read compatibility.

### Segment integration

Dynamic Segments can bind to one exact SavedQuery revision.

Editing the SavedQuery does not silently change an already-bound Segment.
