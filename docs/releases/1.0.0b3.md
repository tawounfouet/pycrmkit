# PyCRMKit 1.0.0b3 — Compatibility Matrix

`1.0.0b3` converts the V1 dependency envelope into a published, executable
compatibility contract.

## Qualified runtime matrix

```text
Python      3.11 / 3.12 / 3.13
PostgreSQL  16 / 17
SQLAlchemy  2.0.x / 2.1.x
psycopg     3.2.x / 3.3.x
FastAPI     0.141.x
Pydantic    2.13.x
Django      5.2.x
DRF         3.18.x
Jinja2      3.1.x
Resend      >=2.47,<3
```

## Persistence cross-matrix

The release gate executes:

```text
PostgreSQL 16 × SQLAlchemy 2.0
PostgreSQL 16 × SQLAlchemy 2.1
PostgreSQL 17 × SQLAlchemy 2.0
PostgreSQL 17 × SQLAlchemy 2.1
```

Each cell covers PostgreSQL repository behavior, migrations and SQLAlchemy
repository contracts.

## Transport edge matrix

FastAPI/Pydantic and Django/DRF are replayed on both supported Python edges:

```text
3.11
3.13
```

Python 3.12 remains covered by the general package matrix.

## Optional extras

The compatibility gate installs/imports:

```text
core
sqlalchemy
postgresql
migrations
fastapi
django
drf
email
resend
fastapi,postgresql,migrations
django,drf,postgresql
```

This catches dependency-resolution conflicts that single-extra tests cannot
detect.

## Metadata alignment

The release tightens install metadata to match the qualified V1 families:

```text
Python              >=3.11,<3.14
SQLAlchemy          >=2.0,<2.2
psycopg             >=3.2,<3.4
FastAPI             >=0.141,<0.142
Pydantic            >=2.13,<2.14
Django              >=5.2,<5.3
DRF                 >=3.18,<3.19
Jinja2              >=3.1,<3.2
```

This prevents unqualified future major/minor releases from being presented as
implicitly supported by package metadata.

CRM behavior.
