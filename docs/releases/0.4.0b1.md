# PyCRMKit 0.4.0b1 — Templates & SMTP

## Added

- Provider-neutral `EmailTemplate` and runtime-checkable `TemplateRenderer`.
- Optional `Jinja2TemplateRenderer` behind the `email` extra.
- Strict undefined-variable behavior and HTML autoescaping for rendered templates.
- Standard-library `SMTPEmailProvider`.
- `SMTPConfig` with plain, STARTTLS, and implicit TLS modes.
- MIME construction for text, HTML, and multipart-alternative email.
- Generated Message-ID, PyCRMKit intent/idempotency headers, and normalized SMTP provider results.
- Error mapping for authentication, recipient/sender rejection, connection, timeout, network, disconnect, and generic SMTP failures.
- Controlled adapter tests without external network access.

## Dependency boundary

The base package remains dependency-free at runtime. Jinja2 is installed only through:

```bash
pip install "pycrmkit[email]"
```

SMTP itself uses only the Python standard library.

- Resend adapter remains scheduled for `0.4.0b2`.
- Delivery/open/click/bounce event ingestion and Communication history integration remain scheduled for `0.4.0rc1`.
