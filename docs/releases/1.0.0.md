# PyCRMKit 1.0.0 — Production Stable

`1.0.0` promotes the fully qualified `1.0.0rc1` contract to the stable V1
line. There is no functional delta between the release candidate and stable
promotion.

## Stable contract

The V1 stable line includes:

- frozen public CRM facade and domain extension points;
- security/privacy hardening and sensitive-data redaction;
- performance regression guardrails;
- Python 3.11–3.13 compatibility;
- PostgreSQL 16/17 with qualified SQLAlchemy/psycopg families;
- transactional persistence, rollback and Alembic migration head `0003`;
- FastAPI and Django/DRF integration boundaries;
- cross-layer production journeys;
- isolated wheel/sdist qualification;
- reproducible release artifact generation.

## Functional delta from RC1

None. Stable promotion does not add a CRM capability, public facade method,
event schema, persistence table or migration.

## Release evidence

Stable promotion produces:

```text
release/
├── qualification-report-v1.0.0.json
├── release-manifest-v1.0.0.json
└── SHA256SUMS-v1.0.0.txt
```

The wheel and sdist are built twice under a fixed `SOURCE_DATE_EPOCH`,
normalized where needed, compared byte-for-byte, checked against frozen
SHA-256 values, and smoke-tested outside the repository checkout.
