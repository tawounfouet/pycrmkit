# PyCRMKit 1.0.0rc1 — Full Production Qualification

`1.0.0rc1` is the V1 production release candidate. It adds no new CRM
capability over `1.0.0b3`; it qualifies the accumulated V1 contract as one
releaseable system.

## Qualification scope

The candidate converges:

- public API freeze;
- security and privacy hardening;
- performance regression baselines;
- Python/dependency compatibility matrix;
- framework-agnostic cross-layer E2E;
- SQLAlchemy/PostgreSQL transactions, rollback and migrations;
- FastAPI → CRM facade → PostgreSQL;
- Django/DRF → CRM facade → PostgreSQL;
- isolated wheel and sdist installation;
- lint, typing and strict documentation builds.

The RC-06 workflow ends in a zero-blocker gate. RC-07 then rebuilds the same
candidate version, records artifact hashes and freezes the release evidence.

## Distribution evidence

RC-07 produces:

```text
release/
├── qualification-report-v1.0.0rc1.json
├── release-manifest-v1.0.0rc1.json
└── SHA256SUMS-v1.0.0rc1.txt
```

The wheel and sdist are rebuilt from the promoted candidate, validated with
`twine check`, executed outside the repository checkout, and hashed with
SHA-256.

## Scope boundary

This promotion changes release metadata and qualification evidence only. It
does not add a domain aggregate, facade method, event schema, persistence table
or migration.
