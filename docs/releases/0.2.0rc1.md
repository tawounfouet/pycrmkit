# PyCRMKit 0.2.0rc1 — Activity & Timeline Integration

This release candidate integrates and freezes the `0.2` Activity, Task and Timeline vertical slices without adding a new business domain.

## Candidate scope

- first-class Activities with historical business occurrence time;
- first-class Tasks with explicit lifecycle transitions;
- immutable Timeline read model projected from meaningful Activity and Task events;
- Contact/Organization relationship-history queries;
- Memory repository adapters and shared Unit of Work transaction semantics;
- event/audit context propagation inherited from the CRM facade;
- candidate public API freeze for the `0.2` line.

## RC qualification scenarios

The RC adds integration coverage for:

1. Contact + Organization + imported historical Activity;
2. Task lifecycle `created → started → completed → reopened → cancelled`;
3. consistent multi-entity Timeline history;
4. exact offset pagination and half-open temporal filtering;
5. projection rollback with the source transaction;
6. idempotent replay of the same source event;
7. installed-wheel smoke of the complete `CRM.memory()` Activity/Task/Timeline path.

## Compatibility intent

The root `0.1` imports remain unchanged. `activities`, `tasks` and `timeline` are additive facade namespaces and are the candidate stable additions for `0.2.0`.

No SQLAlchemy, Django, FastAPI, Sales/Pipeline or durable event-delivery capability is introduced by this RC.
