# PyCRMKit 1.2.0a2 — Campaign Membership & Segment Sources

This release implements **PV1-LOT-009**.

## Delivered

~~~text
Campaign
├── explicit members
│   └── EntityReference
└── Segment sources
    ├── attach
    ├── materialize current population
    ├── refresh explicitly
    └── detach
         ↓
de-duplicated Campaign audience
~~~

### Direct membership

- explicit `CampaignMember` records;
- Contact, Organization, Lead and Opportunity references;
- bounded bulk add/remove operations;
- deterministic pagination;
- duplicate protection;
- existence validation against the same transactional CRM state.

### Segment sources

A Segment source is **captured**, not evaluated live on every read.

Attaching a Segment stores:
- Segment identity;
- Segment revision;
- entity kind;
- attachment timestamp;
- capture timestamp;
- captured member count;
- source metadata.

Later changes to the Segment do not silently change the Campaign audience.
Applications call `refresh_segment_source(...)` to recapture the current
population explicitly.

### Audience semantics

~~~text
explicit members
      +
captured Segment populations
      ↓
de-duplicated EntityReference union
~~~

`members()` returns only direct membership records.

`segment_sources()` returns source provenance.

`audience()`, `audience_count()` and `contains()` operate on the final
de-duplicated Campaign population.

## Compatibility

PyCRMKit 1.1 remains the stable baseline and the 1.2.0a1 Campaign Metadata
surface remains available unchanged. This release is additive.

## Persistence boundary

The Memory adapter is the semantic reference implementation for Campaign
audiences in 1.2.0a2.

SQLAlchemy/PostgreSQL and Django persistence are intentionally deferred to the
1.2 beta milestones.

## Explicitly deferred

~~~text
1.2.0a3  Attribution & Communication Linkage
1.2.0b1  SQLAlchemy/PostgreSQL Campaign Persistence
1.2.0b2  Django Campaign Persistence
1.2.0b3  HTTP + Data Operations Integration
1.2.0rc1 Campaign Production Qualification
~~~

Campaign Segment sources are audience inputs only. This release does not add
campaign delivery, advertising management, cadence execution or advanced
attribution modelling.
