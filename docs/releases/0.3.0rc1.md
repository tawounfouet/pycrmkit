# PyCRMKit 0.3.0rc1 — Sales Integration

This release candidate closes and qualifies the complete `0.3` Sales
Foundation without adding new business scope.

## Candidate scope

- Decimal-safe Money;
- Lead lifecycle and qualification;
- Opportunity domain;
- configurable Pipelines and ordered Stages;
- policy-driven Stage transitions;
- won/lost terminal outcomes;
- atomic and idempotent Lead-to-Opportunity conversion;
- normalized Sales events and transactional audit;
- candidate public API freeze for the `0.3` line.

## RC qualification scenarios

The release candidate adds integrated qualification for:

1. Lead capture and qualification;
2. atomic/idempotent conversion into one Opportunity;
3. Pipeline initial Stage/default probability;
4. rejection of an undeclared transition;
5. allowed `new → qualified → proposal → won` progression;
6. disqualified Lead outcome;
7. `new → qualified → proposal → lost` progression;
8. actor/correlation propagation across Sales events;
9. transactional audit coverage;
10. installed-wheel smoke of the complete `CRM.memory()` Sales path.

## Candidate event set

```text
lead.created
lead.qualified
lead.disqualified
lead.converted
opportunity.created
opportunity.stage_changed
opportunity.won
opportunity.lost
```

Pipeline definition additionally emits `pipeline.created`.

## Compatibility intent

The stable `0.1` and `0.2` contracts remain unchanged. The Sales facade
surface is frozen as:

```text
crm.leads.create/qualify/disqualify/convert
crm.opportunities.create/move
crm.pipelines.define/get/list
```

No new Sales feature scope should be added between this RC and `0.3.0`
stable. Stable promotion is a qualification/release decision, not another
feature milestone.

## Deliberately deferred

This RC does not add SQLAlchemy/PostgreSQL, communication providers, webhooks,
FastAPI, Django, durable event delivery, Sales Timeline projection, analytics
or AI.
