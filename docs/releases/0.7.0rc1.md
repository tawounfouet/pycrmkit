# PyCRMKit 0.7.0rc1 — FastAPI Example + E2E

`0.7.0rc1` qualifies the complete FastAPI integration on the production-reference
PostgreSQL persistence path.

## Reference architecture

```text
HTTP
 ↓
FastAPI routers / ErrorResponse
 ↓
CRMDependency
 ↓
CRM facade
 ↓
SQLAlchemyUnitOfWork
 ↓
PostgreSQL 17
```

The release candidate preserves the central architecture rule: routers never
receive ORM models, SQLAlchemy Sessions or repository implementations directly.

## Reference application

The repository now contains:

```text
examples/fastapi_postgres/
├── app.py
├── compose.yaml
├── .env.example
├── smoke.py
└── README.md
```

`create_app()` owns:

```text
SQLAlchemy Engine
session factory
InProcessEventBus
base CRM facade
FastAPI application lifespan
```

Each request still receives a contextual CRM facade through the existing
FastAPI dependency bridge.

## Migration-first deployment

The reference application deliberately does not alter schemas during startup.

Required deployment order:

```text
install artifact
    ↓
configure PYCRMKIT_DATABASE_URL
    ↓
pycrmkit-migrate upgrade head
    ↓
start ASGI application
```

This keeps migration execution observable and independently controllable.

## PostgreSQL-backed API E2E

The release-candidate test:

```text
reset PostgreSQL schema
      ↓
apply packaged Alembic history
      ↓
create FastAPI application
      ↓
POST Contact
      ↓
POST Organization
      ↓
POST Relationship
      ↓
POST Activity
      ↓
POST + complete Task
      ↓
GET Timeline
      ↓
verify typed 404
      ↓
shutdown application
      ↓
create a new application instance
      ↓
GET persisted Contact / Organization data
```

The restart step proves that successful behavior is not merely in-memory state.

## Installed-wheel qualification

The dedicated CI gate also:

```text
builds wheel + sdist
resets PostgreSQL
creates a clean virtual environment
installs wheel[fastapi,postgresql,migrations]
applies packaged migrations
runs installed-wheel FastAPI/PostgreSQL smoke
verifies OpenAPI
verifies package version
```

This satisfies the release strategy requirement to test the built artifact, not
only the source checkout.

## Core independence

The existing optional-dependency boundary remains qualified:

```text
pip install pycrmkit
import pycrmkit
```

does not require or transitively import FastAPI.

## Stable gate

The FastAPI line now has qualification for:

```text
request validation
response serialization
pagination
domain error → HTTP mapping
OpenAPI generation
router E2E
PostgreSQL-backed API E2E
core import without FastAPI
installed-wheel integration smoke
```

The next delivery is **`0.7.0 — FastAPI Integration Stable`**. Stable promotion
should freeze this qualified behavior without introducing new feature scope.
