# PyCRMKit 1.1.0rc1 — Segmentation Production Qualification

This release implements **PV1-LOT-007**, the final qualification lot before
the stable `1.1.0` promotion.

It adds no new Segmentation capability over `1.1.0b3`. Its purpose is to
freeze and qualify the accumulated 1.1 contract as a production-ready release
candidate.

## Qualification scope

~~~text
V1 compatibility baseline
        +
1.1 Segmentation/SavedQuery contract freeze
        +
Memory semantics
        +
SQLAlchemy/PostgreSQL persistence
        +
Django/DRF integration
        +
FastAPI/OpenAPI integration
        +
Data Operations
        +
Security / performance
        +
wheel / sdist
        ↓
ZERO BLOCKERS
~~~

The candidate freezes:

- portable query expressions and schemas;
- `SavedQuery` revision semantics;
- Static, Dynamic and Snapshot Segments;
- bulk membership contracts;
- Memory / SQLAlchemy / Django adapter semantics;
- Segment import/export integration;
- FastAPI `/segments` and `/saved-queries`;
- DRF Segments and Saved Queries surfaces;
- documented Segmentation/SavedQuery events.

## Scope boundary

No new feature scope is planned between this candidate and stable. A blocking
fix after RC publication requires `1.1.0rc2` and a full relevant qualification
cycle.
