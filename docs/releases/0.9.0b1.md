# PyCRMKit 0.9.0b1 — CSV / JSON / JSONL

`0.9.0b1` connects the generic import framework to the first supported CRM
exchange formats using only the Python standard library.

## Delivered

```text
importers/csv.py
importers/json.py
importers/jsonl.py
exporters/csv.py
exporters/json.py
exporters/jsonl.py
```

## Import adapters

- `CSVReader` — header-driven CSV records with UTF-8/BOM path support.
- `JSONReader` — top-level arrays of JSON objects.
- `JSONLReader` — streaming one-object-per-line records.

All readers satisfy the existing `ImportReader` protocol and can be plugged
directly into `ImportPipeline`.

## Export adapters

- `CSVExporter` — deterministic tabular scalar output.
- `JSONExporter` — streaming JSON array output.
- `JSONLExporter` — streaming line-delimited JSON output.

Exporters return the number of records written and accept either filesystem
paths or text streams.

## Qualification

Coverage includes:

```text
empty input
Unicode
missing CSV values
duplicate source rows
duplicate/invalid CSV headers
extra CSV columns
nested JSON values
malformed JSON
malformed JSONL
non-object JSON records
path round-trips
in-memory stream round-trips
1,000-row JSONL streaming batch
installed-wheel format round-trips
```

## Semantics

Format adapters preserve row order and never deduplicate. CSV is intentionally
scalar/tabular; JSON and JSONL retain nested JSON structures. Structural source
errors are explicit and never silently skipped.

## Scope boundary

No deduplication scoring, candidate ranking or merge execution is introduced in
this beta.
