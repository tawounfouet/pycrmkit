# PyCRMKit 1.1.0 — Segmentation & Sales Task Foundation

`1.1.0` promotes the fully qualified `1.1.0rc1` contract to the stable 1.1
line. There is **no functional delta** between the release candidate and this
stable promotion.

## Stable 1.1 contract

The 1.1 stable line adds to the V1 baseline:

- portable query expressions and deterministic Segment evaluation;
- Static, Dynamic and immutable Snapshot Segments;
- versioned Saved Queries with revision-pinned Segment bindings;
- bulk Segment membership operations;
- sales-task ergonomics and Business Calendar support;
- SQLAlchemy/PostgreSQL Segmentation persistence;
- Django Segmentation persistence;
- Segmentation Data Operations import/export integration;
- FastAPI and DRF Segment/SavedQuery endpoints;
- production qualification across Memory, SQLAlchemy/PostgreSQL, Django/DRF,
  FastAPI/OpenAPI, security, performance and installed distributions.
