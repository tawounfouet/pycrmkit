# PyCRMKit 0.4.0rc1 — Delivery Events & History

This release candidate closes the planned Communication feature scope before stable promotion.

## Added

- Normalized email lifecycle events: queued, sent, delivered, opened, clicked, bounced, failed.
- Append-only EmailDeliveryEvent history with provider callback idempotency.
- Memory persistence for CommunicationIntent, DeliveryAttempt, CommunicationRecord and delivery events.
- Current delivery state on CommunicationRecord with out-of-order callback protection.
- Transactional crm.email namespace for direct or templated outbound email.
- Provider-result persistence and callback ingestion by provider message ID.
- Communication history queries for contacts/organizations and delivery-history queries per record.
- Communication Timeline projection and DomainEvent emission for all seven lifecycle event names.

## Privacy boundary

Domain-event payloads and Timeline metadata contain lifecycle/provider context, not recipient email addresses or message bodies.

## RC scope freeze

No new Communication feature scope is planned after this candidate. Stable 0.4.0 is a qualification/promotion milestone.
