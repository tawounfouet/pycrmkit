# PyCRMKit 0.7.0 — FastAPI Integration Stable

`0.7.0` promotes the fully qualified FastAPI release candidate to stable.

No new FastAPI feature scope is introduced by this release. The objective is to
freeze the behavior qualified by `0.7.0rc1` and establish the `0.7.x`
compatibility baseline.

## Stable integration surface

The stable line includes:

```text
Pydantic transport schemas
CRMDependency request context bridge
offset pagination bridge
ErrorResponse
domain error → HTTP mapping
FastAPI exception handlers
Contacts router
Organizations router
Relationships router
Activities router
Tasks router
Leads command router
Opportunities command router
Timeline router
OpenAPI response contracts/examples
PostgreSQL reference application
```

## Dependency direction

The stable architectural boundary is:

```text
HTTP Request
     ↓
FastAPI Router
     ↓
Pydantic transport schema
     ↓
CRMDependency
     ↓
CRM Facade
     ↓
Domain / Application Services
     ↓
Repository Contracts
     ↓
Adapter
```

A stable FastAPI route must not bypass the CRM facade to access SQLAlchemy
models, Sessions or repositories directly.

## Stable HTTP contracts

The `0.7.x` line compatibility-governs:

```text
documented route paths and HTTP methods
documented request schemas
documented success response schemas
ErrorResponse shape
documented domain-error status mappings
offset pagination semantics
X-Actor-ID / X-Correlation-ID propagation
OpenAPI schema generation
```

Leads and Opportunities remain command-oriented because their public CRM facade
surface is command-oriented. The HTTP integration does not reach through
internal runtime state to invent read APIs.

## Error mapping

```text
ValidationError       → 422
NotFoundError         → 404
ConflictError         → 409
DuplicateError        → 409
InvalidStateError     → 409
RepositoryError       → 500
IntegrationError      → 502
PyCRMKitError         → 500
```

FastAPI request validation uses the same public `ErrorResponse` envelope with
code `request.validation_error`.

## PostgreSQL reference path

The stable example remains:

```text
examples/fastapi_postgres/
```

Deployment order:

```text
install artifact
      ↓
configure PYCRMKIT_DATABASE_URL
      ↓
pycrmkit-migrate upgrade head
      ↓
start ASGI application
```

The application deliberately does not mutate the database schema during
startup.

## Version provenance

The reference FastAPI application now reads its OpenAPI version from
`pycrmkit.__version__`. This removes a duplicated version literal and keeps
package metadata and OpenAPI metadata synchronized.

## Core remains framework-agnostic

A minimal installation still supports:

```bash
pip install pycrmkit
python -c "import pycrmkit"
```

FastAPI and Pydantic remain opt-in dependencies.
