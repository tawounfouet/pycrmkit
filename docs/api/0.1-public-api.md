# PyCRMKit 0.1 Public API

`0.1.0` freezes the first stable CRM Core API for the `0.1.x` release line.

## Shallow imports

The supported root imports are:

```python
from pycrmkit import CRM, CRMConfig, CRMContext, __version__
```

`pycrmkit.__all__` is frozen to those four names for the `0.1.x` line.

Domain-specific types remain available from their bounded-context packages, for example:

```python
from pycrmkit.contacts import Contact, ContactEmail, ContactId, ContactUpdate
from pycrmkit.organizations import Organization, OrganizationId
from pycrmkit.relationships import Relationship, RelationshipEndpoint, RelationshipType
from pycrmkit.tags import Tag, TagId
from pycrmkit.custom_fields import CustomFieldDefinition, CustomFieldType
from pycrmkit.events import DomainEvent, EventId, EventType
from pycrmkit.audit import AuditEntry, AuditEntryId
```

## Stable facade surface

```text
CRM.memory(...)
CRM.with_context(...)
CRM.config
CRM.context

CRM.contacts
CRM.organizations
CRM.relationships
CRM.tags
CRM.custom_fields
CRM.events
CRM.audit
```

The facade names, root imports, domain IDs/value objects, repository protocols, Unit of Work contract, and versioned `DomainEvent` envelope are compatibility-governed within the `0.1.x` line.

## Compatibility policy

For `0.1.x`, patch releases may fix bugs, improve documentation, harden validation, and make internal implementation changes without intentionally breaking the documented public surface above.

A change to one of the following is treated as a compatibility event:

- removing or renaming a supported root import;
- changing the documented facade namespace names;
- changing repository method semantics such as missing-record behavior, pagination ordering, or commit behavior;
- changing the meaning of a published event field without a schema-version transition;
- leaking adapter-specific ORM/session types into public domain APIs.

Deep imports under adapter-internal modules, especially `pycrmkit.storage.memory._state` and `pycrmkit.facade._runtime`, remain internal and are not compatibility promises.

## Qualified runtime matrix

The `0.1.0` release is qualified on:

```text
Python 3.11
Python 3.12
Python 3.13
```

The CRM Core has no mandatory third-party runtime dependency. Development and release tooling remains optional.

## Explicit deferrals

The following are not part of the `0.1` compatibility promise:

- SQLAlchemy/PostgreSQL persistence;
- FastAPI/Django adapters;
- Activity/Timeline/Sales domains;
- webhooks or durable event delivery;
- transactional outbox;
- distributed buses;
- import/export/deduplication;
- AI/agent features.
